COURSE OVERVIEW
This course introduces the principles of Object-Oriented Programming (OOP) in Java, emphasizing problem-solving techniques and software design. Students will explore fundamental OOP concepts, develop interactive applications, and implement efficient programming solutions using modern development tools.
MAIN GOAL
To acquire and apply the fundamental concepts, techniques, and methods of object-oriented programming in Java for problem-solving.
SPECIFIC GOALS
1. Review foundational programming concepts, including variables, data types, control structures, and algorithms.

2. Apply core programming constructs such as arrays, functions, recursion, file I/O, serialization, and hashing.

3. Understand and implement the five key OOP concepts:

   * Classes and objects

   * Abstraction (interfaces/methods)

   * Encapsulation (data hiding)

   * Inheritance

   * Polymorphism

      4. Develop problem-solving skills through hands-on projects and coding assignments.

      5. Utilize debugging techniques, software testing, and version control tools (e.g., Git) to enhance software reliability.



METHODOLOGY
The course combines lectures, coding labs, interactive exercises, and group projects to reinforce learning. Students are expected to:
         * Attend classes regularly and actively participate in discussions.

         * Complete coding exercises, quizzes, and homework assignments to strengthen their understanding.

         * Work in teams on a semester-long project, applying OOP principles to develop a software solution.

         * Use automated assessment tools such as HackerRank for coding evaluations.

         * Engage in peer reviews to refine their programming skills and receive constructive feedback.

Note: Individual projects are allowed only under exceptional conditions (e.g., medical reasons with clinical justification).


COURSE CONTENT
Module 1: Foundations of Programming in Java
            * Variables, Input/Output, and Arithmetic
            * Selection and Iteration Structures
            * Strings and Arrays (Lab 1)

Module 2: Object-Oriented Programming Basics
               * Introduction to Objects and Classes
               * Object Relationships and Method Calls
               * Recursion (Lab 2 & 1st Project Report)
               * Debugging and Unit Testing Techniques

Module 3: Intermediate OOP Concepts
                  * Inheritance and Polymorphism (Lab 3)
                  * Exception Handling and Error Management
                  * File Input/Output and Serialization (Lab 4 & 2nd Project Report)

Module 4: Advanced Topics and Software Development
                     * Graphical User Interfaces and Event Handling (Lab 5)
                     * Hashing and Database Integration
                     * Software Documentation (Javadoc) and Code Conventions
                     * Final Project Report: Full Implementation and Presentation
